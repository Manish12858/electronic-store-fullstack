# Electronic Store - Frontend

React 18 app for the Electronic Store. See the [main README](../README.md) for the full setup.

```bash
npm install
REACT_APP_API_URL=http://localhost:9090 npm start
```

The app runs on http://localhost:3000. `REACT_APP_API_URL` points it at the Spring Boot backend (defaults to http://localhost:9090).
